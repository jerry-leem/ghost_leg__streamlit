# 🪜 사다리타기 게임

Streamlit으로 구현한 인터랙티브 사다리타기 게임입니다.

## 🎮 게임 규칙

사다리타기는 한국의 전통적인 제비뽑기 게임입니다:

1. 사람 수만큼 세로줄을 긋고, 한쪽에는 이름을, 반대쪽에는 상품이나 결과를 적습니다.
2. 세로줄 사이에 가로줄을 무작위로 그습니다.
3. 자신의 세로줄에서 시작하여 아래로 내려가면서:
   - 가로줄을 만나면 반드시 건너갑니다
   - 가로줄이 없으면 계속 직진합니다
4. 최종 도착한 위치의 결과를 받습니다.

## 🚀 실행 방법

### 필수 요구사항

- Python 3.8 이상
- pip

### 설치 및 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 앱 실행
streamlit run app.py
```

브라우저에서 자동으로 `http://localhost:8501`이 열립니다.

## 📋 기능

### 게임 설정
- **참가자 수**: 2명에서 100명까지 설정 가능
- **참가자 이름**: 각 참가자의 이름을 자유롭게 입력
- **결과 설정**: 상품, 당첨 여부 등 원하는 결과를 입력
- **사다리 복잡도**: 가로줄 수를 조절하여 난이도 설정

### 게임 플레이
- **사다리 생성**: 버튼 클릭으로 랜덤 사다리 생성
- **애니메이션**: 참가자 선택 시 경로를 따라가는 애니메이션 표시
- **결과 확인**: 애니메이션 종료 후 최종 결과 표시
- **결과 미리보기**: 스포일러 주의! 모든 결과를 미리 확인 가능

### 기술적 특징
- **랜덤 알고리즘**: 가로줄이 연속되지 않도록 처리
- **경로 추적**: 정확한 경로 추적 알고리즘
- **ASCII 아트**: 터미널 스타일의 사다리 시각화
- **반응형 UI**: 참가자 수에 따라 자동으로 레이아웃 조정

## 🎯 사용 예시

1. **제비뽑기**: 청소 당번, 발표 순서 등을 정할 때
2. **경품 추첨**: 이벤트나 파티에서 경품 추첨
3. **의사 결정**: 여러 선택지 중 하나를 무작위로 선택
4. **게임**: 친구들과 재미있는 게임
